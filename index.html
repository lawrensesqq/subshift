subshift

Fix out-of-sync subtitles. Nothing is uploaded: your file stays in your browser.

Drop an .srt or .vtt file here or

Every subtitle is early or late by the same amount.

Subtitles start in sync and slowly drift, or the delay differs at the start and the end. Pick one line near the start and one near the end, and type when each is actually spoken in the video.

The subtitles were made for a different release (e.g. a 25 fps PAL rip vs 23.976 fps Blu-ray).
